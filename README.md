# 幻瞳界域 1.0.2

**面向 HarmonyOS 手机、平板和二合一设备的全景与 HDR 视频播放器。**

幻瞳界域把本地视频、文件夹、播放列表和网络视频放在同一个播放空间中。你可以观看普通视频，也可以拖动或转动设备探索 360° 全景；导入视频时只保存访问地址，无需把大文件再复制一份到应用目录。

当前版本为 **1.0.2（b6209093）**。下面介绍版本选择、安装方法、主要功能和使用方式。

## 下载与安装

前往本页底部 **Assets** 下载 HAP；仓库首页的用户请打开 [下载页面](https://github.com/DSHwithdsh/PanoVivid-Releases/releases/latest)。

| 安装包 | 适合谁 | 区别 |
| --- | --- | --- |
| 文件名不带 `core` | 需要本地播放及 B 站视频的用户 | 完整版，包含可在设置中关闭的 B 站插件 |
| 文件名带 `core` | 主要播放本地视频的用户 | 精简版，不包含 B 站插件 |

两种包的本地播放、全景、HDR、FEL、超分与插帧、媒体管理和列表功能相同。它们使用同一个应用标识，请选择一种安装。

当前提供 **API 26 / arm64 未签名 HAP**，需要兼容的 HarmonyOS 系统。请通过 **HoKit 或 DevEco Studio**，使用自己的设备授权签名安装；已有用户可用兼容签名覆盖更新，保留收藏与进度。文件名中的 `b` 是构建号，同版本请选择较大的构建号。

## 第一次使用

1. 在「主页」选择左侧 **从文件选择** 或右侧 **从相册选择**，分别使用系统文件选择器或相册打开视频。两个入口均只保存原视频的访问地址。
2. 播放页底部中央为播放 / 暂停，右上角打开播放设置，点击小标题展开或收起选项；普通模式双击画面也可暂停或继续。
3. 退出后，视频会出现在 **最近播放**。再次点击可继续进度，并恢复该视频的普通 / 全景模式；从列表播放的视频还会恢复所属列表和上次的单集循环、列表循环等模式。原列表或条目已移除时回退为单个视频播放。
4. 想长期整理视频，请使用 **文件夹** 或 **列表** 页面。应用保存快捷地址，不搬运原视频。
5. 想播放 B 站视频，请安装完整版，在 **设置 → 插件** 启用 B 站插件，从主页「打开网络地址」粘贴 B 站链接；扫码登录和账号管理在设置的插件页中进入。

## 本地视频与文件夹

- **本地播放**：使用系统选择器授权访问原文件，播放能力由视频封装、编码及设备解码能力共同决定。
- **图库快捷方式**：可通过图库选择视频并保存访问地址，不额外复制媒体文件。
- **最近播放**：自动记忆播放进度和播放模式；可以移除单条记录，也可一键清空，清空前会再次确认。
- **长按操作**：主页最近播放、文件夹及目录内的视频支持长按收藏、添加到列表和删除记录。目录内的删除只隐藏本应用中的条目，可展开「文件夹管理」后用「恢复已隐藏项目」撤销，不删除原文件。
- **收藏与文件夹**：「文件夹」页可收藏视频、文件夹和网络链接。目录支持列表 / 图标视图，点击搜索框右侧图标切换；可读取的视频显示缩略图。点击悬浮 **＋**，向上展开「添加视频」「图库添加」「从文件夹」「收藏链接」四个圆形入口。目录视频右侧星标可切换收藏：实心表示已收藏，空心表示未收藏，并显示操作结果。收藏链接支持使用官方粘贴按钮或长按输入框粘贴整段分享内容，自动提取视频直链、B 站链接或 BV 号及分享标题；手填名称优先，多个链接会提示保留其中一个。
- **地址重新定位**：视频或文件夹被移动、删除，或系统访问授权失效时，会提示重新定位或移除记录。移除快捷记录不会删除原视频。

建议先把视频放到稳定的目录，再添加快捷方式。若在系统文件管理器中移动了文件，请在应用提示时重新选择新位置。

## 播放列表与连续播放

列表内的视频支持 **自定义排序**：长按视频右侧的三点按钮，再上下拖动整条视频至目标位置，松手后自动保存。靠近列表可见区域的顶部或底部时会自动滚动，越靠近边缘速度越快；移回中间或松手即停止。点击三点按钮则打开菜单。切换其他排序后，可再次选择「自定义」恢复手动顺序。「列表管理」展开后依次显示添加视频、添加链接、从收藏添加、重命名和删除列表五个扁平图标，可悬停查看操作提示。视频右侧圆形三点菜单提供重命名、收藏视频和移出列表；仅操作地址记录，不移动原文件。

在 **列表** 页点击圆形 **＋**，向上弹出的三个圆形按钮分别用于「新建列表」「添加视频到列表」和「将文件夹导入为列表」。导入文件夹时会以文件夹名称命名列表。默认只导入当前层；检测到子文件夹时会询问，可选「仅当前文件夹」「继续并包含子文件夹」或关闭取消。确认包含后，所有子文件夹视频平铺加入同一个列表。

「添加视频到列表」可选择已有列表或新建列表，再从文件管理或相册多选视频；也可在列表详情点「添加视频」。重复地址自动合并。列表详情中的「列表管理」「排序」「播放模式」为三个等宽并列入口，默认收起；点击在下方动画展开对应选项，再次点击收起。当前排序和播放模式显示在入口下方。列表首页的排序选项也默认折叠。展开「列表管理」可以添加视频和链接、重命名；展开「排序」可按 **名称、添加时间、创建时间、修改时间** 排序，通过箭头图标切换升降序。文件来源没有提供的时间会显示为未知。

| 播放模式 | 播放到结尾后的行为 |
| --- | --- |
| 播完暂停 | 当前视频结束后暂停 |
| 单集循环 | 重复当前视频 |
| 列表循环 | 按列表顺序播放，末项结束后回到首项 |
| 列表播完暂停 | 顺序播放到列表末项后暂停 |

- 在 **设置 → 列表** 设置默认播放模式、默认排序，以及手动打开视频时是否继续上次进度。
- 列表可以保留自己的播放模式；修改默认值不会覆盖已有列表的独立选择。
- 从列表开始播放后，底部 **上一集 / 下一集** 可切换视频。单独打开的视频没有列表上下文，这两个按钮不会切换内容。

## 360° 全景与小行星

- 可自动识别符合条件的全景视频，并打开全景模式；开关位于 **设置 → 播放**。识别并非对所有片源都准确，必要时可在播放设置中手动切换普通 / 全景。
- **单指拖动** 调整上下、左右视角；也支持鼠标拖动。全景模式屏蔽双击暂停、滑动快进、亮度/音量滑动和应用内侧滑返回，避免与视角操作冲突。点按仍可显示控制栏，控制按钮仍可用。
- 开启 **陀螺仪** 后，转动设备调整视角；「复位视角」可重新确定当前朝向。手持稳定过滤可减轻细小抖动。
- **双指缩放** 调整视野。启用小行星缩放后，可继续缩小进入小行星效果，开关位于设置页。
- 播放菜单提供 **前进视角、小行星视角、超广角视角、地包天视角**，便于一键调整。
- 最近播放会记住该视频的播放模式，再次打开不用重复切换。

高分辨率全景同时消耗解码与图形处理资源。8K、复杂编码或高帧率片源的流畅度取决于设备，不能保证所有内容实时播放。

## HDR、杜比视界与色彩处理

播放器根据片源信息与设备能力选择播放通路，提供已验证的 **PQ / HDR10、HLG** 内容播放；全景模式也有 10 位 HDR 输出通路。

- **普通 HDR 视频**：优先沿用系统播放器与设备支持的解码 / 显示链路，通常不需要手动调节色调曲线。
- **杜比视界内容**：部分格式使用兼容基础层或色彩映射。符合条件的本地 **P7 FEL 双层视频** 使用独立双层解码及合成通路；其他格式不因此改用 FEL 解码器。
- **PS5 WebM / VP9 HDR**：对带有有效 PQ / BT.2020 元数据的片源进行识别和处理。
- 播放页会显示识别到的格式或输出状态；设置页底部可查看设备显示规格。

实际效果取决于片源元数据、编码器、系统版本与屏幕能力。设备具有 HDR Vivid 显示能力，不等于所有 HDR Vivid 片源都已验证可播放；当前没有完成该格式的全面片源验收。杜比兼容播放不代表 Dolby Vision 认证或已完成参考级色彩校准。

## 自动 HDR 增强

在 **设置 → 播放 → 自动 HDR 增强 · 系统 AI HDR** 开启，默认关闭；系统设置中的「视频 HDR 增强」也需开启。

- 使用官方 `XComponent.hdrBrightness(1, HdrType.AIHDR)` 请求显示增强；`videoProcessing` 用于查询和监听状态，不作为执行转换的接口。
- 仅对确认具有 SDR 色彩元数据的普通播放请求增强，并核对当前显示是否报告 `VIDEO_AIHDR`。不按手机型号名称强行启用；未报告能力或状态未确认时如实提示。
- 支持本地及可确认元数据的网络来源，应用不设 3000 像素上限。原生 HDR、杜比/FEL、全景、超分、插帧和画中画保持原通路，避免重复处理。普通网络 MP4/WebM 只做有上限的元数据读取，不复制视频；色彩未知或自适应清单仍保留原画。
- 播放状态区分别显示“已请求”和系统状态；接口返回“未启用”不等于用户关闭了系统设置。实际增强效果、4K 网络流、显示切换与功耗仍需支持设备验证，不能由模拟器证明。

## 超分辨率插件

超分默认关闭。在 **设置 → 插件 → 超分辨率** 选择「关 / Anime4K / FSR1」，也可在 **播放设置 → 画面与超分** 随时切换。

- **Anime4K · 动画超分**：CNN 去噪与二倍放大，适合低分辨率 SDR 动画。独立参数页可设置效果强度和 720p / 1080p 输入上限；降低效果强度只改变画面混合比例，不减少 CNN 运算。
- **FSR1 · 通用超分**：使用 AMD EASU 边缘重建与 RCAS 锐化。独立参数页可设置锐化强度、1.25–2 倍最大倍率和输入上限。锐化设为 0 时跳过 RCAS，保留 EASU；实际倍率按显示区域决定，最多输出到 4K。
- 两个插件独立保存参数，并提供恢复默认按钮。播放工具栏显示当前算法，关闭后仍保留该算法名称。
- 超分实际运行后，短暂显示输入与处理输出分辨率，约 5 秒后隐藏；设置面板可持续查看状态和跳过原因。
- 视频超过屏幕分辨率时自动关闭本次超分；超过插件输入上限、画面无需放大，或 HDR / 杜比 / FEL / 全景内容，保持原画。图形处理失败会回退原画，不表示整台设备的 GPU 均不支持该算法。

超分改变放大处理，不会把 SDR 变成真正 HDR，也不会恢复源文件中不存在的真实细节。

## 轻量插帧插件

在 **设置 → 插件 → 插帧** 开启实验性的「轻量混合插帧」，或在播放设置的「画面与超分」中开关。默认关闭。

- 使用 GPU 混合相邻帧，可选 30 / 60 fps 目标上限；它不是 AI 或运动补偿插帧，快速运动可能出现重影。
- 可调整重影抑制：差异较大的像素改用相邻原帧。提高抑制会减少重影，同时减弱平滑感。
- 仅用于最高 1080p 的普通 SDR 视频和正常速度播放；源帧率已达目标、帧间隔异常、暂停和跳转时不混合旧帧。HDR、杜比和全景保持原帧率。
- 视频增加约一源帧延迟（通常 17–50 毫秒），声音保持原播放时钟。目标帧率不保证在所有设备上达到，介意延迟或重影时请关闭。

## B 站与网络视频

**仅完整版提供 B 站插件。**

1. 在 **设置 → 插件** 打开 B 站视频功能。
2. 在设置的 B 站插件页点「打开插件」，选择扫码登录，用 B 站 App 扫码并确认；同设备可使用「保存二维码到相册」，然后在 B 站 App 的扫一扫中从相册选择二维码，确认授权后返回播放器。二维码过期后可刷新，也保留网页登录入口。无需向开发者提供密码或 Cookie。
3. 解析完成后进入原生播放页。底部最右侧、动画超分右边的 **清晰度** 按钮可选择该账号和片源实际提供的画质；切换会保留进度与播放 / 暂停状态。
4. 符合条件的全景视频可使用全景模式。扫码授权后尝试 APP 取流并请求 HDR Vivid；只有服务器实际返回该画质才列出，不能保证所有账号和片源可用。HDR 播放取决于返回视频流与设备能力，HDR10 不会被标成 HDR Vivid。
5. 遇到海外卡顿，可在插件设置尝试网络加速，以及 **自动 / 国内 CDN / 海外 CDN**。选项效果因地区和源站而异，若没有改善可关闭。

可在 **设置 → 插件 → B 站视频** 使用「退出账号并清除授权」，清除本机 Cookie 和扫码凭据，保留收藏、列表和进度。扫码凭据优先保存到系统 Asset Store，保存失败时会提示仅本次会话有效。

插件不提供超出账号权限的画质或内容。账号、地区限制、链接过期、源站接口变化均可能影响使用。主页「打开网络地址」同时支持普通视频直链、B 站视频链接、b23.tv 短链接、BV 号和含链接的分享文字；B 站短链接会先解析为视频地址，再交给已启用的插件在应用内播放；解析失败时提示原因，不自动打开网页。插件关闭时会提示启用，精简版会提示使用完整版。网络地址输入框提供「清空」和官方安全「粘贴」按钮，仅主动点击粘贴时读取剪贴板。WebDAV 尚未作为正式功能提供。

触屏自由变换只影响视频内容，不改变系统窗口方向。触控板直接双指旋转不受当前 ArkUI 接口支持，使用 Alt＋滚动进行旋转。物理触控板手感仍需设备验收。

## 紧凑播放栏与系统画中画

**紧凑播放栏**位于应用内的 Dock 上方，显示最近或当前视频。页面下滑后，播放栏移至 Dock 右侧并持续并排，直到回到接近页面顶部才恢复上下排列；顶部回弹不会作为下滑重新触发。两条底栏整体居中；窄屏布局会收拢为缩略图圆球。点击可回到播放页，向上拖动时，外层光感气泡放大，内部封面由圆形逐渐变成居中的圆角矩形，并同步放大圆角，动画末端仍保留明显圆角，气泡铺满后再过渡到全屏播放；短拖取消后平滑恢复。

**系统画中画**在 **设置 → 界面 → 退出视频后系统画中画** 开启。它提供播放 / 暂停、快进 / 后退、恢复与关闭等操作；也可选择「退出应用时关闭小窗播放」。应用内紧凑播放栏和系统画中画是两种不同的界面。

- 画中画的移动、尺寸范围与窗口交互受系统管理；当前已验证拖动及边角缩放。
- 系统画中画的屏幕和触控板双指捏合缩放尚未实现；普通播放页内的视频变换与系统小窗缩放不同。
- 全景进入系统小窗时按当前显示比例创建；手机会短暂读取重力姿态，检测为竖向握持时使用竖屏比例。无传感器、平放或读数超时时回退当前窗口比例，不强制更改二合一窗口模式。
- 画中画内尚不支持播放完自动跨视频切集；恢复播放页后可继续列表操作。
- 二合一设备尊重当前窗口模式，进入播放不会强制把桌面窗口切成全屏。

## 界面、按键与沉浸光感

- 选择「跟随系统」方向时，返回播放会以当前窗口的横竖方向为起点，之后跟随系统旋转设置，不重新套用上次播放的方向。

- 紫罗兰配色与二次元人物主页，提供适配手机和平板的布局。向下浏览主页时，人物插画与标语逐渐向顶部缩小收拢，回到顶部恢复。
- 播放主按钮固定在底部中央；在 **设置 → 界面** 调整辅助按键顺序、显示项目及排列位置，并查看当前布局预览。按键布局仅在应用设置页调整，播放页不重复提供入口。
- 播放设置按「播放」「画面与超分」「全景与视角」分组（全景组选项仅在 360 模式显示），点击标题动画展开／收起，一次展开一组。方向选择「跟随系统」时遵循系统自动旋转开关。
- 主页文件／相册入口和列表、设置、播放菜单的选项采用支持独立沉浸材质的官方 Chip 组件，保留紫罗兰选中态。
- 官方沉浸光感可选择 **关、弱、均衡、强、和系统保持一致**。「关」保留基础 UI 样式；效果依赖系统与设备支持情况。
- Dock 选中页面以紫色图标和文字区分；紧凑播放栏不显示方形悬停底色。展开播放栏时，Dock 会连续受压避让：上下排列时压低上边缘，并排时向远离播放栏的一侧压缩；展开途中不反复弹跳，取消后平滑恢复。
- 点击或向上拖动紧凑播放栏可展开为播放页，展开过半即开始加载视频，画面就绪后封面渐隐，由视频接替。圆球展开从第一帧保持四边等距和同心圆角。关闭系统画中画时，返回的外气泡还原为原来的长条播放栏或圆球，实时视频同时回到封面位置，与播放栏左侧圆弧同心；动画结束后停止播放，过程中不切换截图。
- 进入设置子页面时，Dock 和紧凑播放栏一起向左滑出；返回一级页面时滑回。
- 竖屏保留摄像头避让，手机横屏播放不为摄像头额外留边；底部手势区域仍保留安全距离；桌面全屏下系统顶栏显隐遵循系统窗口能力。
- 智感握姿支持时，可让文件夹与列表添加按钮适应握持位置；紧凑播放栏缩成圆球后，圆球靠近握持手并与 Dock 左右换位，并在设置中开关；不支持的设备隐藏该开关。

## 当前需要了解的限制

- 文件格式支持不是无限的；8K、特殊编码、复杂 HDR 和高码率网络片源可能出现兼容性或性能问题。
- FEL 色彩尚未经过仪器校准；长片、8K FEL 和 360° FEL 完整合成仍需进一步验证。
- 手机缩略图圆球布局仍需更多机型实测；沉浸光感和智感握姿的能力范围由系统决定。
- 系统画中画双指缩放、画中画自动跨视频切集和 WebDAV 尚未完成。
- 系统 AI HDR 需当前显示报告能力；状态查询本身不执行增强，未完成真机验证前不保证实际 HDR 增强效果。
